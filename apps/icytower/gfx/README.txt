[Icy Tower Base Game Graphics]
================================
Due to copyright reasons, the original base game assets are not distributed with this port.

To play:
1. Obtain the original PC version of Icy Tower (v1.4, v1.5 or v1.3).
2. Copy all .bmp files from the original game's 'gfx' folder into this directory (sd:/apps/icytower/gfx/).

Required core files:
- floor01.bmp through floor27.bmp
- bgtile.bmp
- clock.bmp, clock_hand.bmp
- combo_meter.bmp, combo_liquid.bmp, combo_count.bmp
- sideblock.bmp
- font1.bmp, font2.bmp, font3.bmp
- harold/ folder (with idle, jump, walk bmp sprites)
