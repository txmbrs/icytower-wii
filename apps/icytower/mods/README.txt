[Tower Mods System Guide]
===========================
Icy Tower Wii features a custom Tower Mods system allowing you to completely transform
the tower's visual aesthetics, platforms, background, walls, UI, and music.

Included Tower Mods:
- HollowKnight: Gothic Hallownest wrought-iron openwork bridges, organic shell tower walls, Greenpath mist, and Knight player sprite.
- Minecraft: Pixel-perfect block platforms (grass, stone, obsidian, netherite), cobblestone walls, and Minecraft skybox.
- Cyberneon: Glowing neon retrowave synth aesthetic with laser platforms and dark cyber walls.
- Matrix: Digital rain green data stream aesthetic.

How to select a Mod:
- In the main menu, go to Options -> Tower Mod and use Left/Right to switch themes.

How to create your own Tower Mod:
1. Create a new folder in sd:/apps/icytower/mods/<YourModName>/gfx/
2. Add your custom textures (.png or .bmp):
   - floor01.png - floor27.png: Platform textures (left cap 21x37, mid tile 16x37, right cap 21x37)
   - sideblock.png: Tower wall texture (132x124)
   - bgtile.png: Tower background texture (546x128)
   - combo_meter.png, combo_liquid.png, combo_count.png: Custom combo UI
   - harold/: Optional character override sprites
3. Launch the game and your mod will automatically appear in the Tower Mod selection!
